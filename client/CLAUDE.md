## Theming — two surfaces, "Palco" and "Studio"

The app runs **two** themes, split by audience:

- **"Palco"** — the dark broadcast/awards language for the **public** surfaces (`/` voting, `/score` Classifica): near-black neutral stage, hairline-bordered solid surfaces (no glassmorphism), one reserved accent (electric gold `#ffb020`), Space Grotesk for display type / numerals, Inter for body. Each candidate's configured `color` is a small identity accent (left rule, number, bar fill), never a full card wash. This is the default — no class needed.
- **"Studio"** — a light, professional workspace theme for `/admin` and `/manager` only. Applied via a `.theme-pro` host class on `AdminShellComponent` and `EventManagerShellComponent` (`host: { class: 'theme-pro' }`). The `.theme-pro` block in `styles.scss` only **re-points the shared token set and Material's `--mat-sys-*` variables** (plus the default-palette `emerald/amber/red` 100–400 steps, darkened for white) inside that subtree — so every existing utility (`bg-bg-card`, `text-accent-cyan`, `.glass`) and every Material component re-skins with no per-file edits. Accent is a sober deep amber `#b45309` (the brand gold, calmed for paper). Overlay surfaces render in the CDK overlay (outside the shell), so they opt in explicitly: the event `<mat-select>` has `panelClass="theme-pro"`, and `MAT_DIALOG_DEFAULT_OPTIONS` in `app.config.ts` sets `panelClass: 'theme-pro'` for every `ConfirmDialogComponent` (all dialogs in the app are admin/manager-side).

Design tokens live in the `@theme` block of `client/src/styles.scss`. **Token names are legacy** ("Neon Dark" era): `accent-cyan` is the one accent (gold on Palco, amber on Studio); `accent-magenta` / `accent-violet` are now aliases pointing back at it (kept only so a stray reference can't resurrect a second hue); `accent-yellow` is the champagne "victory" tone reserved for the winner beat; `accent-coral` is the legacy error name, realigned to the danger ramp. The `emerald/amber/red` status ramps are overridden in `@theme` to a warm, desaturated set so "aperto" green doesn't read cool next to the stage. `--color-on-accent` is the ink on a filled accent surface (dark on Palco, white on Studio) — use it, never a hard-coded hex. The `--radius-*` scale is re-pointed so the steps cluster (~10 / ~14 / 16 / 20).

Shared component primitives live in the `@layer components` block of `styles.scss` and are the single source for buttons/cards/inputs: `.btn` + `.btn-primary` / `.btn-tinted` / `.btn-ghost` / `.btn-danger` (+ `.btn-sm`), `.surface-card` (16px hairline card, same look as `.glass`), `.surface-panel` (14px nested), `.field-input` (text inputs). Call sites add only layout utilities. Native checkbox/radio/`input[type=color]` are styled globally. `.glass` is a flat surface, `.gradient-title` a **solid** display treatment (display font + tight tracking, colour from `--color-text-primary` — no gradient fill on text), `.neon-text` just the display font. Reduced-motion is handled globally at the bottom of `styles.scss`.

`client/src/styles/_material-theme.scss` defines a custom M3 theme (`mat.theme()`, dark, yellow/orange palettes) whose system CSS variables (`--mat-sys-primary`, `--mat-sys-surface`, etc.) are re-pointed at the Palco hex values. The mixin is still named `neon-dark-theme()` for the `@include` in `styles.scss`. Angular Material components are used for genuinely interactive chrome (`MatDialog` for the confirm-destructive-action pattern — see `ConfirmDialogComponent` — and `MatSnackBar` for toasts via `ToastService`); highly custom visual elements (score buttons, candidate cards, hero banner, Classifica reveal) stay hand-rolled CSS/Tailwind. Tailwind v4 is wired via `@tailwindcss/postcss` (not `@tailwindcss/vite`, since the Angular CLI's esbuild-based builder doesn't take Vite plugins).

The Classifica presenter ceremony (`/score` in `presenterMode`) renders as full-screen broadcast title cards: one position at a time as a headline with a count-up on the final score (`CountUpDirective`, `client/src/app/shared/count-up.directive.ts`), earlier positions collapse into a ladder; gold-tinted "terzo classificato" beat, twin panels for the "finale a due", gold takeover for the winner (with "pari merito" tie handling). Motion is deliberately theatrical but restrained: the position number lands with `.animate-stage-slam` (oversized + soft → snap), the ladder staggers in, and the winner card gets the softened `winnerGlow` halo plus the count-up — no gradient wash, no light sweep. All of it collapses under `prefers-reduced-motion`.
