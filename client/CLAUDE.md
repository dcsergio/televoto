## Theming — `DESIGN.md` is the source of truth

The repo-root **`DESIGN.md`** ("twilight summit command center", dark-only) is the single source of truth for the site's style; this section only documents how it is implemented. Change DESIGN.md first, then mirror it here. `client/DESIGN.md` is the superseded "Palco/Studio" spec — ignore it.

One dark theme for the whole app — public surfaces (`/vote`, `/score`) and operational workspaces (`/`, `/manager`) alike. There is no light variant and no theme toggle (the former `ThemeStateService` / `.studio-dark` were removed). `.theme-pro` is still set as a host class on `AdminShellComponent` / `EventManagerShellComponent` and as `panelClass` on the event `<mat-select>` and on every dialog (`MAT_DIALOG_DEFAULT_OPTIONS` in `app.config.ts`), but it is now only a **marker** carrying Material patches for those screens (disabled `<mat-chip>` status badges forced back to full-ink labels; bare `<h1>`–`<h4>` defaulting to primary ink in `@layer base` behind `:where()`) — it no longer switches palette.

Design tokens live in the `@theme static` block of `client/src/styles.scss`. It declares the DESIGN.md palette under its canonical names (`--color-midnight-indigo`, `--color-slate-indigo`, `--color-carbon-iris`, `--color-twilight-plum`, `--color-iris-border`, `--color-graphite`, `--color-steel`, `--color-smoke`, `--color-ash`, `--color-bone`, `--color-ember-coral`, `--color-electric-blue`, `--color-arc-violet`, `--color-chartreuse`, plus `--gradient-ember-coral` / `--gradient-alpine`) and re-points the **legacy token names** used by utilities across the templates at them:
- surfaces: `bg-primary` = Midnight Indigo (canvas), `bg-card` = Slate Indigo, `bg-secondary` = Carbon Iris (inset wells), `bg-card-hover` = Twilight Plum; `border-glass` = Iris Border; `border-neon` = Arc Violet (selection).
- ink: `text-primary` = Bone, `text-secondary` = Ash, `text-muted` = Smoke (DESIGN.md names Smoke "secondary", but Ash is lighter — mapped to keep the hierarchy monotonic).
- `accent-cyan` (legacy name) = the one interactive accent: Arc Violet lifted toward Bone (`color-mix`) so it clears AA as small text. `accent-magenta` / `accent-violet` alias it. `accent-yellow` (Classifica winner beat) = the coral sunrise tone; `accent-coral` (error) = Ember Coral. `--color-on-accent` = Bone.
- status: DESIGN.md's functional mapping — Electric Blue = in progress (`signal-open`, "votazione aperta"), Chartreuse = done (the `emerald-*` ramp), coral sunrise tone = warning (`signal-warn`, the `amber-*` ramp), Ember Coral = blocked/danger (`signal-danger`, the `red-*` ramp).
- type: `--font-display` = Inter Tight (DESIGN.md's substitute for the custom "Index" face), body Inter; `"tnum"` on globally; weights capped at 400/500/600 (`--font-weight-bold|extrabold|black` all = 600); letter-spacing always within 0.003em–0.015em (no negative tracking, no wide-tracked eyebrows — use `tracking-[0.015em]` at most).
- shape: `--radius-pill` 30px for every interactive element (buttons, inputs, pills, score buttons), cards 12–20px (`--radius-xl` / `--radius-2xl`), feature panels 24px.
- elevation: none. `--shadow-card` is empty and `--shadow-lift` / `--shadow-gold` are 1px hairline rings; surfaces float by luminance + border. The only glow is DESIGN.md's "Gradient CTA Glow Ring" (`--shadow-glow-ring`), used by the Classifica winner (`winnerGlow`).

Shared component primitives live in the `@layer components` block of `styles.scss` and are the single source for buttons/cards/inputs: `.btn` (30px pill) + `.btn-primary` (**the coral→red gradient — the only filled button, one per view**) / `.btn-tinted` (Twilight Plum + violet hairline) / `.btn-ghost` (Steel hairline) / `.btn-danger` (Ember Coral hairline) (+ `.btn-sm`), `.surface-card` (Slate Indigo, 20px), `.surface-panel` (Carbon Iris inset, 12px), `.field-input` (pill input on a Carbon Iris well), `.status-pill` + `.status-open|warn|danger|neutral` (DESIGN.md "Status Tag Pill"), `.notice-*`. Call sites add only layout utilities. Never use blue/violet/red as a filled background for a button. `.glass` is the flat card, `.gradient-title` a **solid** Bone display treatment (no gradient on text), `.neon-text` just the display font. The shell `<mat-toolbar>`s are DESIGN.md's "Frosted Nav Bar" (`!bg-bg-card/60` + backdrop blur + Iris hairline). The alpine gradient appears only as the hero glow behind the event title (`HeroBannerComponent`). Reduced-motion is handled globally at the bottom of `styles.scss`.

`client/src/styles/_material-theme.scss` defines a custom M3 theme (`mat.theme()`, dark, violet/rose palettes) whose `--mat-sys-*` variables are re-pointed at the DESIGN.md tokens, plus overrides for 30px pill buttons/outlined fields, Slate Indigo dialogs/select panels/snackbars (1px Iris border, no shadow), and `mat-flat-button` painted with the coral gradient. The mixin is still named `neon-dark-theme()` for the `@include` in `styles.scss`. Angular Material components are used for genuinely interactive chrome (`MatDialog` for the confirm-destructive-action pattern — see `ConfirmDialogComponent` — and `MatSnackBar` for toasts via `ToastService`); highly custom visual elements (score buttons, candidate cards, hero banner, Classifica reveal) stay hand-rolled CSS/Tailwind. Tailwind v4 is wired via `@tailwindcss/postcss` (not `@tailwindcss/vite`, since the Angular CLI's esbuild-based builder doesn't take Vite plugins).

The Classifica presenter ceremony (`/score` in `presenterMode`) renders as full-screen broadcast title cards: one position at a time as a headline with a count-up on the final score (`CountUpDirective`, `client/src/app/shared/count-up.directive.ts`), earlier positions collapse into a ladder; accent-tinted "terzo classificato" beat, twin panels for the "finale a due", `accent-yellow` (coral sunrise) takeover for the winner (with "pari merito" tie handling). Motion is deliberately theatrical but restrained: the position number lands with `.animate-stage-slam` (oversized + soft → snap), the ladder staggers in, and the winner card settles into the `winnerGlow` glow ring plus the count-up — no gradient wash, no light sweep. All of it collapses under `prefers-reduced-motion`.
